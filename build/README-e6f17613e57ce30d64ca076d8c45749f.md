# Live L4 inference-control experiment

The implementation is present, but the live controller comparison has not reached
confirmation. Two independent 210 MHz steady trials completed all 32 requests
validly. Neither acquisition reached its bursty trial because cooling failed to
return to the initial reference within the permitted time. No clock has qualified
on both patterns, and no measured energy winner is claimed.

The latest bounded retry, `fixed-feasibility-v2-20260905T0300Z`, ran on one
Standard L4 in `us-central1-b` from 02:52:12.738626 UTC on 5 September 2026.
It stopped at 03:37:23.029416 UTC with `conditioning_timeout`; VM and boot-disk
cleanup was verified at 03:38:53.269200 UTC and independently checked afterward.
The 900-second wait preserved the original temperature criteria and 77/79 C
watchdogs. The last eligible 60-second window was entirely 57 C, with zero GPU
utilization and mean instantaneous board power of 21.4174 W. Its allowed upper
mean was 50.6995 C, a 6.3005 C gap. This window excludes server teardown.
Smoke and 210 MHz steady passed; 210 MHz bursty and both 660 MHz trials were
unstarted. Extending the wait alone did not resolve qualification.

The initial reference was 49.6995 C, compared with 54.3088 C in the first
qualification. The code accepts a 60-second temperature range of at most 1 C;
that does not establish thermal equilibrium or a repeatable warm idle state.
It also does not exclude samples preceding the cooling-clock command from that
window. These observations motivate revisiting startup conditioning. They do not
prove the reference could never be reached or justify changing the recorded
acceptance criteria. Both acquired source bundles remain unchanged.

The acquisition planned five fixed-clock trials. It performed no capacity test,
batch sweep, model fitting, controller optimization, power forecasting, or
confirmation protocol freeze. It supplies no calibration to the fixed-clock
controller. The earlier 64.8 W calibration and the interrupted 40 W development
attempt remain archived; neither supplies predictions in this test.

The client reproduces trace prompt and output lengths using deterministic
synthetic token-ID prompts and forced output lengths. It records SSE receipt
times and token IDs; final server metrics supply each request's mean inter-token
latency (ITL). Stream chunks do not identify individual token-generation times.
Missing usage or latency fields invalidate the smoke test. The report retains
request-level p95 time to first token (TTFT) and p95 mean ITL without setting a
shared latency target.

Valid energy windows extend from the first scheduled arrival through final
completion, including drain. Failed or incomplete requests, watchdog events,
missing telemetry brackets, excessive telemetry gaps, or more than 1% of
dispatches over 100 ms late invalidate a trial. Aborted energy remains a
measurement of truncated work. It cannot support an efficiency claim for the
full workload. Reports retain invalid and unstarted trials alongside completed measurements.

The broader fixed-clock/governor/MPC comparison has not reached confirmation.
It would require a completed development calibration and a frozen protocol
before any paired confirmation runs. The separate thermal candidate and its
acceptance criteria remain frozen.
