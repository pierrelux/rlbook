A. Backward induction finite horizon, deterministic

Q1core2 min

Backward induction is run on a problem with horizon \(T\), terminal cost \(c_\mathrm{T}\) and dynamics \(\mathbf{x}_{t+1} = \mathbf{f}_t(\mathbf{x}_t, \mathbf{u}_t)\). What does it return?

  1. aOne optimal control sequence \(\mathbf{u}_1^\star, \dots, \mathbf{u}_{T-1}^\star\) for the given initial state, like a transcribed NLP
  2. bA cost-to-go \(J_t^\star(\mathbf{x})\) and a decision rule \(\pi_t^\star(\mathbf{x})\) for every stage \(t\) and every state \(\mathbf{x}\); both depend on \(t\) in general
  3. cA single stationary value function \(J^\star(\mathbf{x})\), the fixed point of the Bellman operator, obtained by value iteration
  4. dA local optimum near the initial guess

Answer: (b)

Backward induction starts at the last stage and works back to the first. At each stage \(t\) and for every state \(\mathbf{x}\) of the grid, it solves the one-step problem

\[ J_t^\star(\mathbf{x}) = \min_{\mathbf{u}} \big\{ c_t(\mathbf{x}, \mathbf{u}) + J_{t+1}^\star(\mathbf{f}_t(\mathbf{x}, \mathbf{u})) \big\}. \]

It stores two things: the minimum value \(J_t^\star(\mathbf{x})\) and the minimizer \(\pi_t^\star(\mathbf{x})\). So the output is two arrays indexed by stage and state: a value table and a feedback policy. Both depend on \(t\), because with a fixed horizon the cost from \(\mathbf{x}\) depends on how many stages remain.

Why not the others

  • (a) A single control sequence for one initial state is what trajectory optimization returns. Backward induction answers for every state; to get the sequence from \(\mathbf{x}_1\), you roll the policy forward.
  • (c) A single stationary value function, found by value iteration, belongs to the infinite-horizon discounted problem. Here the values change with \(t\), and the recursion ends after \(T\) steps.
  • (d) There is no initial guess. If each one-step minimization is solved exactly, the result is the global optimum.

Q3core2 min

A reservoir system has 4 reservoirs, each with one release, over 52 weekly stages. Compare how many numbers each approach has to handle.

  1. Backward induction discretizes each storage into 100 levels and stores one cost-to-go value for every grid state at every stage. How many values is that?
  2. Transcription for one given initial state makes the 4 storages and the 4 releases at each stage the decision variables of an optimization problem. How many variables is that?
  1. a(i) \(52 \times 4 \times 100 \approx 2 \times 10^4\) values; (ii) about 400 variables
  2. b(i) \(52 \times 100^4 \approx 5 \times 10^9\) values; (ii) \(52 \times (4 + 4) \approx 400\) variables
  3. c(i) \(52 \times 4^{100}\) values; (ii) about 400 variables
  4. dAbout 400 for both, since both use the same 52 stages

Answer: (b)

(i) Backward induction. The grid contains every combination of levels of the 4 storages:

\[ 100 \times 100 \times 100 \times 100 = 100^4 = 10^8 \text{ grid states per stage}. \]

One value per grid state and per stage gives \(52 \times 10^8 \approx 5 \times 10^9\) values, and each one requires its own minimization over the releases. The count is exponential in the number of reservoirs: the curse of dimensionality.

(ii) Transcription. At each of the 52 stages there are 4 storages and 4 releases, so \(52 \times (4 + 4) = 416 \approx 400\) variables. That grows only linearly with the number of reservoirs.

The trade-off. The transcription is far smaller, but it answers for one initial state only. The table gives the optimal decision from every state at every stage.

Why not the others

  • (a) \(4 \times 100\) counts the levels of each storage separately. The grid needs every combination of levels, so the levels multiply: \(100^4\).
  • (c) \(4^{100}\) swaps base and exponent. It is (levels per storage) to the power (number of storages): \(100^4\).
  • (d) Both use 52 stages, but at each stage the table covers all \(10^8\) grid states, while the transcription follows a single trajectory.

Q4core2 min

Backward induction stores the cost-to-go only at grid nodes, spaced 10 hm³ apart. A release sends the storage to 1033.7 hm³, which is not a node: it lies between the nodes 1030 and 1040, where the stored next-stage values are \(v_{t+1}(1030) = 50\) and \(v_{t+1}(1040) = 60\). To estimate \(v_{t+1}(1033.7)\), we can either

  1. round to the nearest node and use its stored value, or
  2. interpolate linearly between the two nodes.

What estimate does each method give?

  1. a(i) 50; (ii) \(0.63 \cdot 50 + 0.37 \cdot 60 = 53.7\)
  2. b(i) 60; (ii) 55
  3. c(i) 50; (ii) \(0.37 \cdot 50 + 0.63 \cdot 60 = 56.3\)
  4. dNeither works: we must simulate again from 1033.7

Answer: (a)

Rounding takes the nearest node. 1033.7 is 3.7 from 1030 and 6.3 from 1040, so it uses \(v_{t+1}(1030) = 50\).

Linear interpolation measures how far we are along the interval:

\[ \lambda = \frac{1033.7 - 1030}{10} = 0.37. \]

The weight on the far node is \(\lambda\) and the weight on the near node is \(1 - \lambda\):

\[ \hat J_{t+1} = (1 - 0.37)\cdot 50 + 0.37 \cdot 60 = 31.5 + 22.2 = 53.7. \]

The closer node (1030) gets the larger weight, 0.63. Both methods use nonnegative weights summing to one, so the result always lies between the stored values. A cubic spline can have negative weights and overshoot.

Why not the others

  • (b) 1040 is not the nearest node (it is 6.3 away, against 3.7 for 1030), and 55 is the midpoint, which ignores where 1033.7 sits.
  • (c) The rounding part is right, but the interpolation puts the larger weight on the far node: the weights are swapped.
  • (d) The point of storing a table is that no new simulation is needed: we only combine stored numbers.

  2. bNothing: the argmin of \(c_t(\mathbf{x}, \mathbf{u}) + \hat J_{t+1}(\mathbf{f}_t(\mathbf{x}, \mathbf{u}))\) is unchanged by a constant shift; only the ordering the cost-to-go induces over actions matters for the policy

Q6core8 min, on paper

Consider a system with one state \(x_t\) and one control \(u_t\), both real numbers, and linear dynamics

\[ x_{t+1} = x_t + u_t. \]

We make two decisions, at \(t = 0\) and \(t = 1\), and want to minimize the total cost

\[ \tfrac12\big(x_0^2 + u_0^2\big) + \tfrac12\big(x_1^2 + u_1^2\big) + \tfrac12 x_2^2. \]

Each stage penalizes the distance of the state from 0 and the size of the control, and the final state \(x_2\) is penalized too. In the usual LQR notation, this is the case \(A = B = Q = R = Q_T = 1\) with horizon \(T = 2\).

  1. Suppose the optimal cost-to-go from stage \(t+1\) is quadratic, \(J_{t+1}^\star(x) = \tfrac12 P_{t+1} x^2\) for some number \(P_{t+1}\). Write the one-step problem that defines \(J_t^\star(x)\), minimize it over \(u\) by setting the derivative to zero, and show that the optimal control has the form \(u_t^\star = -K_t x_t\). Give the gain \(K_t\) as a function of \(P_{t+1}\).
  2. Substitute \(u_t^\star\) back into the one-step problem. Show that \(J_t^\star(x) = \tfrac12 P_t x^2\) is again quadratic, and give \(P_t\) as a function of \(P_{t+1}\). This is the Riccati recursion for this system.
  3. Start from the terminal cost, \(P_2 = Q_T = 1\), and compute \(K_1, P_1, K_0, P_0\). What is the optimal total cost from \(x_0 = 2\)?
  4. Now imagine a much longer horizon and run the recursion backward for many stages. To what value does \(P_t\) converge, and what is the corresponding gain?

(a) The gain

Backward induction says: the best cost from \(x\) at stage \(t\) is the cost paid now plus the best cost from wherever we land:

\[ J_t^\star(x) = \min_u \Big\{ \underbrace{\tfrac12\big(x^2 + u^2\big)}_{\text{cost now}} + \underbrace{J_{t+1}^\star(x')}_{\text{cost from the next state}} \Big\}. \]

Where does the term \(P_{t+1}(x + u)^2\) come from? Not from the stage cost: it comes from the cost-to-go. We assumed \(J_{t+1}^\star\) is quadratic, \(J_{t+1}^\star(x') = \tfrac12 P_{t+1}\,x'^2\), and the dynamics say the next state is \(x' = x + u\). Substituting:

\[ J_{t+1}^\star(x + u) = \tfrac12 P_{t+1}(x + u)^2. \]

So the one-step problem at stage \(t\) is

\[ J_t^\star(x) = \min_u \tfrac12\Big[\, x^2 + u^2 + P_{t+1}(x + u)^2 \,\Big]. \]

Set the derivative in \(u\) to zero:

\[ u + P_{t+1}(x + u) = 0 \quad\Longrightarrow\quad u_t^\star = -K_t\, x, \qquad K_t = \frac{P_{t+1}}{1 + P_{t+1}} \]

This is the general \(K_t = (R + B^\top P_{t+1} B)^{-1} B^\top P_{t+1} A\) with every matrix equal to 1.

(b) The Riccati recursion

Under \(u^\star\), the next state is \(x + u^\star = (1 - K_t)\,x = \dfrac{x}{1 + P_{t+1}}\). Substitute:

\[ P_t = 1 + K_t^2 + P_{t+1}(1 - K_t)^2 = 1 + \frac{P_{t+1}}{1 + P_{t+1}} \]

(c) Two stages, from \(P_2 = Q_T = 1\)

  • No grid or interpolation was needed: the value function stays exactly quadratic.

Q7core2 min

Which statement about the finite-horizon LQR solution is correct?

  1. aThe cost-to-go stays exactly quadratic, \(\tfrac12 \mathbf{x}^\top P_t \mathbf{x}\), so backward induction carries one matrix per stage instead of a table; \(R_t \succ 0\) makes the one-step minimization in \(\mathbf{u}\) well posed, and the policy is linear, \(\mathbf{u}_t^\star = -K_t \mathbf{x}_t\)
  2. bThe Riccati recursion runs forward in time from \(P_0 = Q_0\)
  3. cOne needs \(Q_t \succ 0\) strictly; \(R_t = 0\) is fine
  4. dThe gain \(K_t\) depends on the current state \(\mathbf{x}_t\)

Answer: (a)

Start backward induction from a quadratic terminal cost \(\tfrac12\mathbf{x}^\top Q_T\mathbf{x}\). At each stage, the one-step problem is a quadratic in \(\mathbf{u}\) (quadratic cost plus quadratic cost-to-go of a linear next state). Setting its gradient to zero gives a control that is linear in the state, \(\mathbf{u}_t^\star = -K_t\mathbf{x}_t\). Substituting back gives again a quadratic, \(\tfrac12\mathbf{x}^\top P_t\mathbf{x}\). So one matrix \(P_t\) per stage replaces the whole table. That backward update of \(P_t\) is the Riccati recursion.

The minimization is well posed when \(R_t + B_t^\top P_{t+1}B_t\) is positive definite, which \(R_t \succ 0\) guarantees.

Why not the others

  • (b) The recursion starts at the end, \(P_T = Q_T\), and runs backward, like all backward induction.
  • (c) It is the other way around: \(Q_t \succeq 0\) is enough, but with \(R_t = 0\) the matrix \(B_t^\top P_{t+1}B_t\) can be singular, and then the minimizer in \(\mathbf{u}\) need not be unique.
  • (d) \(K_t\) is computed offline from \(A, B, Q, R, P_{t+1}\) only. The state enters linearly, through \(-K_t\mathbf{x}_t\).

Q82 min

iLQR is run on the boat-docking problem. Besides a nominal plan \((\bar{\mathbf{x}}_t, \bar{\mathbf{u}}_t)\), it returns gains \(K_t\). The boat is then perturbed by noise during execution and the controller applies \(\mathbf{u}_t = \bar{\mathbf{u}}_t - K_t(\mathbf{x}_t - \bar{\mathbf{x}}_t)\). Which statement is correct?

  1. aThis is MPC, since it uses the measured state
  2. bThis is a local, time-varying feedback controller: it corrects deviations inside a tube around the nominal trajectory where the linearization holds, without re-solving anything; with too much noise the state leaves the tube and the correction fails
  3. cThe gains make the controller globally optimal for the nonlinear system
  4. dThe gains are only used during optimization and are discarded afterward

Answer: (b)

Each iLQR iteration linearizes the dynamics and approximates the cost by a quadratic around the current plan, then solves that local LQR problem with a Riccati backward pass. The backward pass produces gains \(K_t\) as a by-product. During execution, \(\mathbf{u}_t = \bar{\mathbf{u}}_t - K_t(\mathbf{x}_t - \bar{\mathbf{x}}_t)\) corrects the deviation from the plan with a fixed, precomputed gain per stage: a time-varying linear feedback, with no optimization at run time.

It works only where the linearization is accurate, in a tube around the nominal trajectory. Large noise pushes the boat out of that tube, and the correction can fail.

Why not the others

  • (a) MPC re-solves an optimization from each measured state. Here nothing is re-solved; the gains were computed once.
  • (c) The gains come from a local, linearized model, so they are only locally valid, not globally optimal.
  • (d) The gains are exactly what makes the controller useful after optimization: they give feedback for free.

Q10core2 min

Policies can be Markovian or history-dependent, deterministic or randomized (classes MD, MR, HD, HR). Which statement is correct for a finite-horizon MDP with finite states and actions?

  1. aHR policies can do strictly better, because they use more information
  2. b\(\Pi^{MD} \subset \Pi^{HR}\), and the supremum over \(\Pi^{HR}\) is attained by a policy in \(\Pi^{MD}\); that policy is in general nonstationary, one decision rule per stage
  3. cAn optimal policy exists in \(\Pi^{MD}\) and it is always stationary
  4. dRandomized policies are needed whenever the transitions are random

Answer: (b)

Markov deterministic policies are a special case of history-dependent randomized ones, so \(\Pi^{MD} \subset \Pi^{HR}\). The surprising part is that nothing is lost by restricting to MD. Two facts give this:

  1. State sufficiency. With Markov dynamics and rewards, the best you can do from a given history depends only on the current state. Remembering the past does not help.
  2. No gain from randomizing. When maximizing an expectation, a mixture of actions is worth at most the best action: \(\sum_a q(a)w(a) \le \max_a w(a)\).

The optimal MD policy still has one decision rule per stage, because the number of remaining stages matters.

Why not the others

  • (a) More information can only help if it predicts the future, and the current state already summarizes everything relevant.
  • (c) The MD part is right, but with a finite horizon the optimal rule depends on \(t\) (see Q2 and Q9), so it is not stationary in general.
  • (d) Random transitions do not call for random actions: by fact 2, a deterministic choice is always at least as good.

Q11core2 min

Two policies on a two-state problem have expected returns \(v^{\pi_A} = (3, 5)\) and \(v^{\pi_B} = (4, 4)\), one entry per initial state. Which is better?

  1. a\(\pi_A\), because its total \(3 + 5\) is larger
  2. b\(\pi_B\), because its worst case is larger
  3. cNeither: under the componentwise partial order the two are not comparable. An optimal policy must be at least as good as both in every state
  4. dThey are equally good, since \(3 + 5 = 4 + 4\)

Answer: (c)

MDPs compare policies state by state: \(\pi\) is at least as good as \(\pi'\) if \(v^\pi(s) \ge v^{\pi'}(s)\) in every state. Check:

  • state 1: \(3 < 4\), so \(\pi_B\) is better there;
  • state 2: \(5 > 4\), so \(\pi_A\) is better there.

Neither dominates, so they are not comparable: this order is partial. The remarkable fact of MDP theory is that an optimal policy exists that is at least as good as every other policy in every state at once, so it beats both.

Why not the others

  • (a) and (d) Summing over states is a different criterion (it amounts to a uniform initial distribution). It is not the order used to define optimality.
  • (b) Comparing worst cases is also a different criterion. Nothing in the question asks for it.

Q122 min

The inflow to a reservoir network is a 6-dimensional continuous random vector, and the Bellman backup needs \(\mathbb{E}_{\mathbf{w}}[J_{t+1}(\mathbf{f}_t(\mathbf{x}, \mathbf{u}, \mathbf{w}))]\). You replace the expectation by an average over \(M\) simulated inflows. Which statement is correct?

  1. aThe estimator only needs a simulator of \(\mathbf{w}\), not its density, and its standard error decreases like \(1/\sqrt{M}\) whatever the dimension of \(\mathbf{w}\)
  2. bIts error decreases like \(1/M^6\), as for a tensor-product quadrature rule
  3. cIt is biased unless \(M\) exceeds the number of grid states
  4. dIt requires the transition matrix \(p(\mathbf{x}' \mid \mathbf{x}, \mathbf{u})\) in closed form

Answer: (a)

The Monte Carlo estimate is

\[ \frac1M \sum_{i=1}^M J_{t+1}\big(\mathbf{f}_t(\mathbf{x}, \mathbf{u}, \mathbf{w}_i)\big), \qquad \mathbf{w}_i \text{ simulated}. \]

For targets \(y = (y_1, y_2)\), \(\hat\theta = (y_1 + 2y_2)/5\), so

\[ \mathsf{P}y = \hat\theta \begin{pmatrix} 1 \\ 2 \end{pmatrix}, \qquad \mathsf{P} = \frac15\begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix} \]
  • \(\mathsf{P}(1, 1) = (3/5, 6/5) \ne (1, 1)\): constants are not preserved, so \(\mathsf{P}\) is not an averager.
  • Second row: absolute sum \(6/5 > 1\), so \(\mathsf{P}\) is not a sup-norm nonexpansion.
  • \(\mathsf{P}\) is an orthogonal projection in the unweighted \(\ell_2\) norm; the trouble is that \(\mathsf{L}\) is not a contraction in that norm.

Q37core3 min

Linear policy evaluation with features \(\boldsymbol\Phi\) fits with weights \(\xi\): \(\mathsf{P} = \boldsymbol\Phi(\boldsymbol\Phi^\top\boldsymbol\Xi\boldsymbol\Phi)^{-1}\boldsymbol\Phi^\top\boldsymbol\Xi\), \(\boldsymbol\Xi = \mathrm{diag}(\xi)\). When is \(\mathsf{P}\mathsf{L}_\pi\) a \(\gamma\)-contraction in \(\|\cdot\|_\xi\)?

  1. aFor any \(\xi\), since \(\mathsf{P}\) is an orthogonal projection
  2. bWhen \(\xi\) is the stationary distribution of the evaluated policy, \(\xi^\top\mathbf{P}_\pi = \xi^\top\): \(\mathsf{P}\) is a nonexpansion in \(\|\cdot\|_\xi\) by Pythagoras for any \(\xi\), but \(\mathsf{L}_\pi\) contracts in \(\|\cdot\|_\xi\) only for that \(\xi\). This is why TD needs on-policy data
  3. cOnly when \(\xi\) is uniform
  4. dWhenever \(\xi\) is the stationary distribution, also for the optimality operator with the max

Answer: (b)

We need both operators to be nonexpansive or contractive in the same norm, \(\|\cdot\|_\xi\).

Step 1: \(\mathsf{P}\) is a nonexpansion in \(\|\cdot\|_\xi\), for any \(\xi\). The weighted fit makes \(v - \mathsf{P}v\) orthogonal (in the \(\xi\) inner product) to the span. By Pythagoras,

\[ \|v\|_\xi^2 = \|\mathsf{P}v\|_\xi^2 + \|v - \mathsf{P}v\|_\xi^2 \;\ge\; \|\mathsf{P}v\|_\xi^2. \]

Step 2: \(\mathsf{L}_\pi\) contracts in \(\|\cdot\|_\xi\) only when \(\xi^\top\mathbf{P}_\pi = \xi^\top\). By Jensen, \(\big((\mathbf{P}_\pi v)(s)\big)^2 \le (\mathbf{P}_\pi v^2)(s)\). Weight by \(\xi\) and use stationarity:

\[ \|\mathbf{P}_\pi v\|_\xi^2 \le \xi^\top\mathbf{P}_\pi v^2 = \xi^\top v^2 = \|v\|_\xi^2. \]

So \(\|\mathsf{L}_\pi v - \mathsf{L}_\pi w\|_\xi = \gamma\|\mathbf{P}_\pi(v - w)\|_\xi \le \gamma\|v - w\|_\xi\). Combined with step 1, \(\mathsf{P}\mathsf{L}_\pi\) is a \(\gamma\)-contraction. This is why TD needs on-policy data.

Why not the others

  • (a) \(\mathsf{P}\) is fine for any \(\xi\), but \(\mathsf{L}_\pi\) is the problem: step 2 needs stationarity.
  • (c) Uniform \(\xi\) works only if the uniform distribution happens to be stationary for \(\pi\).
  • (d) With the max, the greedy policy changes with \(v\), so there is no single stationary distribution to weight by.

Q39core2 min

A fitted value method repeats: compute targets \(y_i = (\mathsf{L}v_{\theta_k})(s_i)\) at sampled states, then call fit on the pairs \((s_i, y_i)\) to get \(\theta_{k+1}\). Which statement is correct?

  1. aIt is gradient descent on the fixed loss \(\sum_i \big((\mathsf{L}v_\theta)(s_i) - v_\theta(s_i)\big)^2\), the "Bellman loss"
  2. bIt is two nested loops: successive approximation outside, a regression on targets frozen at \(\theta_k\) inside. The targets move between outer steps, so it is not gradient descent on a fixed loss; any regressor with a fit method (trees, forests, neural networks) gives such a method
  3. cIt only works with linear features
  4. dIt is guaranteed to converge because \(\mathsf{L}\) is a contraction

Answer: (b)

Read the loop as two nested loops.

  • Outer loop (successive approximation). Compute targets \(y_i = (\mathsf{L}v_{\theta_k})(s_i)\) with the current \(\theta_k\), then freeze them.
  • Inner loop (regression). Fit \(v_\theta\) to the frozen pairs \((s_i, y_i)\). Any regressor with a fit method works: linear model, trees, forests, neural network.

Together: \(v_{k+1} = \mathsf{P}\mathsf{L}v_k\), with \(\mathsf{P}\) the regressor. The targets change at every outer step, so there is no single loss being minimized.

Why not the others

  • (a) Gradient descent on the residual \(\sum_i((\mathsf{L}v_\theta)(s_i) - v_\theta(s_i))^2\) would also differentiate the target \(\mathsf{L}v_\theta\) with respect to \(\theta\). Fitted methods freeze the target, so they do something different.
  • (c) The inner fit can be any regressor. Fitted Q iteration with trees, NFQ and DQN are examples.
  • (d) \(\mathsf{L}\) contracts, but the regressor may not be a nonexpansion in the same norm, so convergence is not guaranteed in general (Q33 to Q36).
