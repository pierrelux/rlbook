A. Decision variables and the program OCP, transcription, first-order conditions

Q1core2 min

"The big conceptual thing, always the source of confusion, is the definition of our decision variables." Which statement about decision variables is correct?

  1. aIn the continuous-time OCP, the unknown \(u\) is a vector of snapshots of the action at the mesh times
  2. bIn direct transcription, the decision variables are the values of the state and of the control at the nodes, and the dynamics enter as equality constraints (a consistency condition at every step)
  3. cIn single shooting, both \(\mathbf{x}\) and \(\mathbf{u}\) are decision variables, but \(\mathbf{x}\) is initialized by simulation
  4. dThe transcribed NLP searches directly in the space of control functions

In the continuous problem \(u(t)\) is a function, not a vector of snapshots. We never search in the space of functions; we search in a space of parameters, here the nodal values. Transcription produces a finite NLP whose solution is a tuple \((\mathbf{u}^\star_{1:T-1}, \mathbf{x}^\star_{1:T})\), with \(\mathbf{x}_{t+1} = f(\mathbf{x}_t, \mathbf{u}_t)\) imposed as an equality constraint. Single shooting eliminates the states altogether: only the controls remain, and \(\mathbf{x}\) is whatever the rollout produces.

Rehearses: saying what the unknowns are in each formulation.

Q2core2 min

A cart-pole swing-up is transcribed directly: 31 state nodes \(\mathbf{x}_1,\dots,\mathbf{x}_{31}\) with \(n=4\) states each, 30 scalar controls \(u_1,\dots,u_{30}\), and a fixed initial state. How many decision variables does the NLP have, and how many equality constraints come from the dynamics plus the initial condition?

  1. a154 variables, 124 equalities
  2. b30 variables, 0 equalities
  3. c154 variables, 120 equalities
  4. d124 variables, 154 equalities

Variables: \(31\cdot 4 + 30 = 154\). Equalities: 30 consistency conditions of size 4 give 120, plus 4 for \(\mathbf{x}_1 = \mathbf{x}_{\text{init}}\), so 124. Option (b) is what remains after eliminating the states by simulation: single shooting, 30 unknowns and no equality constraints. "Mathematically it's the same program. Numerically it's never the case."

Each residual depends only on \((\mathbf{x}_k, u_k, \mathbf{x}_{k+1})\), so the constraint Jacobian is block banded. That is the structure a Newton or SQP step exploits when it solves its linear system.

Q3core7 min, on paper

Consider the two-step problem \[ \min_{u_1,u_2}\; 2x_3^2 + u_1^2 + u_2^2 \quad\text{s.t.}\quad x_{t+1} = x_t + u_t,\; t=1,2,\qquad x_1 = 1, \] written with the states as decision variables.

  1. Write the Lagrangian with multipliers \(\lambda_2,\lambda_3\) on the two consistency conditions, written as \(x_t + u_t - x_{t+1} = 0\).
  2. Write the first-order optimality conditions: the derivative of the Lagrangian with respect to \(x_2, x_3, u_1, u_2\) is zero, plus the two constraints.
  3. This is a root-finding problem \(F(\mathbf{z}, \boldsymbol\lambda) = 0\). Solve it by hand. Report \(u^\star\), \(x_3^\star\), \(\lambda^\star\), and the optimal cost.
  4. What would Newton's method do with these equations? Would it invert a matrix?

(a) \(\mathcal{L} = 2x_3^2 + u_1^2 + u_2^2 + \lambda_2(x_1 + u_1 - x_2) + \lambda_3(x_2 + u_2 - x_3)\).

(b) \(\partial_{x_3}: 4x_3 - \lambda_3 = 0\). \(\partial_{x_2}: -\lambda_2 + \lambda_3 = 0\). \(\partial_{u_1}: 2u_1 + \lambda_2 = 0\). \(\partial_{u_2}: 2u_2 + \lambda_3 = 0\). Plus \(x_2 = 1 + u_1\), \(x_3 = x_2 + u_2\).

(c) \(\lambda_2 = \lambda_3 =: \lambda\), \(u_1 = u_2 = -\lambda/2\), and \(x_3 = 1 - \lambda\). Then \(\lambda = 4x_3 = 4(1-\lambda)\) gives \(\lambda^\star = 4/5\), \(u^\star = (-2/5, -2/5)\), \(x_3^\star = 1/5\), cost \(2/25 + 8/25 = 2/5\). Check by eliminating: with \(u_1 = u_2 = u\), \(\tfrac{d}{du}\left[2(1+2u)^2 + 2u^2\right] = 8(1+2u) + 4u = 0\) gives \(u = -2/5\).

(d) Newton treats \(F = \nabla_{\mathbf z,\boldsymbol\lambda}\mathcal L\) as a function whose root we want and iterates \(\mathbf{y}_{k+1} = \mathbf{y}_k - [J_F(\mathbf{y}_k)]^{-1}F(\mathbf{y}_k)\). Here \(F\) is linear, so one step lands on the answer. It never forms the inverse: it solves the linear system \(J_F\,\delta = -F\) ("\(A\delta = b\), np.linalg.solve, never inv"). Quadratize the Lagrangian, linearize the constraints, solve, repeat: that is SQP.

Notice the structure of the \(x\)-equations: \(\lambda_3\) is set by the terminal cost and \(\lambda_2\) is obtained from \(\lambda_3\). The multipliers propagate backward from the end. That backward pass is what the notes call the adjoint or costate recursion, and it is the same computation as backprop through the rollout.

Rehearses: writing first-order optimality conditions for a transcribed problem and solving a small instance.

Q4core2 min

A colleague wants to solve \(\min_{\mathbf z} f(\mathbf z)\) s.t. \(h(\mathbf z) = 0\). They form \(f(\mathbf z) + \lambda\, h(\mathbf z)\) with a fixed \(\lambda = 1\), minimize it over \(\mathbf z\) with Adam, and call this "the Lagrangian method". What is wrong?

  1. aNothing; this is exactly Arrow–Hurwicz
  2. bThe Lagrangian defines a game: \(\min_{\mathbf z}\max_{\lambda}\mathcal{L}\). With \(\lambda\) frozen they solved a penalized problem whose minimizer is not feasible in general; it is the max player who, by driving \(\lambda\), forces \(h = 0\)
  3. cThey should have used \(\mu \ge 0\) instead of \(\lambda\)
  4. dAdam cannot be used on a Lagrangian

This is the "Lagrangian fallacy": the construction of a Lagrangian is not a regularized problem. If the min player picks an infeasible \(\mathbf z\) with \(h(\mathbf z) = 1.2\), the max player cranks \(\lambda\) up to infinity. The existence of multipliers \((\lambda^\star, \mu^\star)\) at a solution is the first-order condition; it does not say how to find them. Arrow–Hurwicz plays the game with simultaneous gradient descent on \(\mathbf z\) and gradient ascent on \(\lambda\). Option (c): \(\mu \ge 0\) is for inequality constraints \(g \le 0\).

Rehearses: what the Lagrangian is and is not.

Q5core3 min

Inspect this primal–dual (Arrow–Hurwicz) update for \(\min f(\mathbf z)\) s.t. \(h(\mathbf z) = 0\), \(g(\mathbf z) \le 0\), with \(\mathcal L = f + \lambda^\top h + \mu^\top g\). Which lines are wrong?

for k in range(iters):
    z   = z   - alpha * grad_z_L(z, lam, mu)   # line 1
    lam = lam - beta  * h(z)                   # line 2
    mu  = mu  + beta  * g(z)                   # line 3
  1. aLine 1 should be gradient ascent on \(\mathbf z\)
  2. bLine 2 has the wrong sign (\(\lambda\) must ascend: \(+\beta\, h\)), and line 3 is missing the projection \(\mu \leftarrow \max(0, \mu + \beta g)\)
  3. cOnly line 3 is wrong; the dual variables should use the same step \(\alpha\)
  4. dThe code is correct: this is gradient descent–ascent

"What's important is the sign: you've got a minus and you've got a plus." The primal variable descends on \(\mathcal L\), the dual variables ascend on it, because the dual player maximizes. Inequality multipliers must stay nonnegative, so after the ascent step they are clipped: \(\Pi\) is literally np.maximum(0, ...). Different step sizes for primal and dual are allowed and often needed (two-time-scale updates); the method is only locally convergent and can oscillate, which is the same instability GAN training shows.

Rehearses: reading an optimizer loop and spotting the sign and projection errors.

Q62 min

An SQP step on \(\min f\) s.t. \(h = 0\) solves \[ \begin{bmatrix} \nabla^2_{\mathbf{zz}}\mathcal L & J_h^\top \\ J_h & 0 \end{bmatrix} \begin{bmatrix} \Delta\mathbf z \\ \Delta\boldsymbol\lambda \end{bmatrix} = - \begin{bmatrix} \nabla_{\mathbf z}\mathcal L \\ h \end{bmatrix}. \] Which statement is correct?

  1. aThis is Newton's method applied to the first-order optimality conditions, viewed as a root-finding problem \(F(\mathbf z, \boldsymbol\lambda) = 0\)
  2. bEvery intermediate iterate satisfies \(h(\mathbf z) = 0\)
  3. cThe matrix should be inverted once and reused at every iteration
  4. dConvergence is quadratic from any starting point

"Root-finding problems are all you need." Quadratize the Lagrangian, linearize the constraints, solve the QP, repeat. The step satisfies the linearized constraint \(h + J_h\Delta\mathbf z = 0\), not the nonlinear one, so SQP is an infeasible-path method: think of infeasible iterates as exploration, not as a mistake. The matrix changes every iteration, is never inverted explicitly (solve \(A\delta = b\)), and Newton's convergence is quadratic but only local.

B. Simultaneous versus sequential single shooting as elimination

Q7core2 min

The semi truck is docked by single shooting: the states are eliminated through the rollout \(\boldsymbol\phi_t(\mathbf{u}, \mathbf{x}_1)\), and L-BFGS-B optimizes the 320 steering and speed inputs. Which requirement can you not impose as a hard constraint in this formulation?

  1. aA box bound \(|\delta_t| \le \delta_{\max}\) on every steering angle
  2. bA hitch-angle bound \(|\beta_t| \le 60^\circ\) at every time step
  3. cA terminal penalty on the final pose
  4. dA penalty on the steering rate \(\delta_{t+1} - \delta_t\)

The hitch angle is a state, and the states are no longer decision variables. All you can do is penalize \(\beta_t(\mathbf{u})\) inside the objective: you can regularize, you cannot enforce. "It's a price you pay." Controls are explicit, so box bounds and rate penalties on them are fine, and a terminal penalty is just part of the objective. With a simultaneous method the states are explicit, so a state constraint is one more inequality at each node.

Q8core2 min

A problem statement describes a deep-space probe: a very long horizon, dynamics with unstable modes, and a requirement that the state stays inside a safe region at all times. Which approach fits, and why?

  1. aSingle shooting with Adam, since it has the fewest unknowns
  2. bA simultaneous method such as collocation: the states are decision variables, so the safe region becomes bound constraints at the nodes, and the equality constraints pin down the unstable modes instead of letting a long rollout explode
  3. cSingle shooting with exact gradients from reverse-mode AD, which removes the long-horizon problem
  4. dMPPI, because it needs no gradients

Three cues, same answer. Long horizon: a shooting objective chains \(T\) steps of dynamics, like backprop through time, and the gradient explodes or vanishes. Unstable dynamics: the simulation itself blows up far from a good guess, whereas the simultaneous method anchors the trajectory at every node. State constraints: only explicit states can be bounded. Exact gradients (c) do not change the conditioning; they only compute the same badly scaled gradient faster. MPPI (d) is also a shooting method and has no built-in constraint mechanism.

Rehearses: recognizing the cue in a problem description and picking the method.

Q9core6 min, on paper

Dynamics \(x_{t+1} = x_t + u_t\), \(x_1 = 1\), \(T = 4\), objective \(J = x_4^2 + \sum_{t=1}^{3} u_t^2\).

  1. Eliminate the states: write \(x_4\) as a function of \(\mathbf u = (u_1, u_2, u_3)\).
  2. Write the reduced single-shooting objective \(J(\mathbf u)\) and its gradient.
  3. Evaluate the gradient at \(\mathbf u = \mathbf 0\), then take one gradient step with step size \(0.1\). Does the cost go down?
  4. Find the minimizer of \(J(\mathbf u)\) and the optimal cost.
  5. Write the same problem as a simultaneous NLP (variables and equality constraints). Do the two formulations have the same solution?

(a) \(x_4 = 1 + u_1 + u_2 + u_3\).

(b) \(J(\mathbf u) = (1 + u_1 + u_2 + u_3)^2 + u_1^2 + u_2^2 + u_3^2\), so \(\partial J/\partial u_t = 2x_4(\mathbf u) + 2u_t\). Q102 min

For the backing truck, a hitch-angle error grows by a factor \(e\) for every 10 m of reversing (\(L_1 = 10\) m). The plan backs up 30 m. Roughly how does the gradient of a terminal-pose penalty with respect to the first steering input compare with the gradient with respect to the last one?

  1. aAbout the same; both act on the same trajectory
  2. bAbout 3 times larger
  3. cAbout \(e^3 \approx 20\) times larger
  4. dAbout \(e^{-3}\) times, so 20 times smaller

The derivative with respect to an early control passes through the product of all later dynamics Jacobians: for \(x_{t+1} = a x_t + u_t\) it is \(a^{T-1-t}\). Backing is the unstable (jackknife) direction, so the factors exceed one and compound to \(e^{d/L_1}\); driving forward they shrink to \(e^{-3}\). Think of it as an exploding gradient problem. The book's measured ratio at the seed was about 800 to 0.04. That spread is a conditioning problem for any fixed-step method; Adam rescales one coordinate at a time and does not undo the coupling.

Rehearses: linking unstable dynamics to the conditioning of single shooting.

Q112 min

Single shooting computes \(\nabla_{\mathbf u} J\) by backprop through the rollout (scan). Which statement is correct?

  1. aOne forward rollout plus one backward pass gives the gradient with respect to every control; the backward pass propagates a vector through transposed Jacobians (vector–Jacobian products) without ever forming them
  2. bYou need one rollout per control, as in finite differences
  3. cThe Jacobians \(\partial f/\partial \mathbf x\) must be formed explicitly and multiplied together
  4. dThe gradient with respect to \(u_1\) only involves the first step of the dynamics

The backward pass starts from the gradient of the terminal cost and accumulates one VJP per step, so the cost is one forward and one backward sweep, at the price of storing (or checkpointing) the trajectory. "The golden rule: never form Jacobian matrices explicitly." This backward recursion is what the notes write as the adjoint (costate) equation of the Pontryagin principle: forward dynamics, backward multipliers, and the derivative with respect to each \(u_t\) assembled from them. For us it is a way to compute the shooting gradient, not a tool for analytical solutions. Finite differences cost one rollout per control, and \(u_1\) affects every later state, so its gradient involves the whole chain.

Rehearses: what reverse-mode AD does and why the adjoint recursion is backprop.

Q132 min

Multiple shooting has more unknowns than single shooting on the same problem. Why is it nevertheless easier to solve on long horizons?

  1. aThe extra unknowns make the constraints linear
  2. bA derivative passes through at most \(L\) dynamics Jacobians before hitting a decision variable, so sensitivities cannot compound across the whole horizon
  3. cIt avoids numerical integration altogether
  4. dIt needs no initial guess for the controls

Single shooting chains the dynamics across \(T\) steps, the exploding or vanishing gradient problem of unrolled recurrent networks. Multiple shooting cuts the chain every \(L\) steps and asks a constrained solver to glue the pieces with continuity constraints, whose Jacobian is sparse: constraint \(k\) depends on \(x_k\), \(x_{k+1}\), and the controls of segment \(k\) only. Integration is still used inside each segment, and the initial guess still matters.

D. Collocation nodal representation, operators, the recipe, schemes

Q14core2 min

A polynomial can be written in the monomial form \(p(\tau) = \sum_j a_j \tau^j\) or in the nodal (Lagrange) form \(p(\tau) = \sum_j y_j \ell_j(\tau)\). Why does collocation insist on the nodal form?

  1. aThe unknowns are then the values of the state at the nodes, so bound constraints on the state are direct, and differentiation and integration become precomputed matrices acting on those values
  2. bLagrange polynomials can represent functions that monomials cannot
  3. cThe nodal form avoids the fundamental theorem of calculus
  4. dThe nodal form is fitted by least squares to samples of the true trajectory

Same space of polynomials, different coordinates: \(\mathbf y = V\mathbf a\) with \(V\) invertible for distinct nodes. In the nodal form \(\ell_j(\sigma_i) = \delta_{ij}\), so the coefficient \(y_j\) is the value at node \(j\); "search not over coefficients but over chosen values of the polynomial". That makes the state explicit in the NLP (bounds, stability) and gives derivative and integral "for free": \(p'(\sigma_i) = \sum_j D_{ij} y_j\) and \(\int_0^1 p = \mathbf w^\top \mathbf y\), exact, no autodiff, no finite differences. The polynomial passes through the nodal values exactly: this is interpolation, not regression; there is no loss being fitted.

Rehearses: the nodal versus monomial distinction, "maybe the third time I've presented this".

Q15core8 min, on paper

Nodes \(\sigma = (0, \tfrac12, 1)\) on the unit interval.

All three nodal values satisfy \(x \le 3\), yet the piece violates the bound between nodes. Nodal bounds bound the piece itself only for constant or linear pieces.

Q16core8 min, on paper

Apply the three-step recipe (choose collocation points; match slopes to \(f\) there; impose the endpoint values so the pieces are stitched together) on one interval \([t_k, t_{k+1}]\) of length \(h\), with the interval clock \(\tau \in [0,1]\). Write \(f_k = f(x_k,u_k)\) and \(f_{k+1} = f(x_{k+1},u_{k+1})\).

  1. Collocation points \((0, 1)\). Interpolate the slope \(\dot x_h\) with the Lagrange basis on these two nodes.
  2. Integrate from the start of the interval (fundamental theorem of calculus) to get the state piece \(x_h(\tau)\). What degree is it?
  3. Impose \(x_h(1) = x_{k+1}\). Which scheme is this? Write its collocation condition and the matching discretization of \(\int c\,dt\) over the interval.
  4. Repeat with a single collocation point \(\tau_1 = 0\), then \(\tau_1 = 1\). Which schemes result? Why does the "implicit" one cost nothing extra in direct transcription?

(a) \(\ell_0 = 1 - \tau\), \(\ell_1 = \tau\), so \(\dot x_h(t_k + h\tau) = f_k(1-\tau) + f_{k+1}\tau\): the slope is linear across the interval.

(b) \(x_h(\tau) = x_k + h\int_0^\tau \left[f_k(1-s) + f_{k+1}s\right]ds = x_k + h\left[f_k\left(\tau - \tfrac{\tau^2}{2}\right) + f_{k+1}\tfrac{\tau^2}{2}\right]\). Quadratic: one degree above the slope, as integration always gives.

(c) \(x_{k+1} = x_k + \tfrac{h}{2}(f_k + f_{k+1})\): the trapezoidal collocation condition, which stitches this interval to the next through the shared variable \(x_{k+1}\). The cost uses the same weights, \(\tfrac{h}{2}(c_k + c_{k+1})\), the trapezoidal rule. The quadrature is prescribed by the collocation scheme; you do not pick it independently.

(d) One node means a constant slope. \(\tau_1 = 0\): \(x_{k+1} = x_k + h f_k\), explicit Euler, with the rectangle rule \(h c_k\). \(\tau_1 = 1\): \(x_{k+1} = x_k + h f_{k+1}\), implicit Euler. In simulation, implicit Euler needs Newton at every step because \(x_{k+1}\) appears on both sides. In transcription \(x_{k+1}\) is already a decision variable and the condition is just another equality constraint, so the two cost the same.

Q17core7 min, on paper

One interval, trapezoidal collocation. Dynamics \(\dot x = -x + u\) on \([0,1]\), so \(h = 1\). Boundary conditions \(x(0) = 1\) and \(x(1) = 0\). Decision variables \(x_0, x_1, u_0, u_1\), control linear on the interval. Minimize \(\tfrac12(u_0^2 + u_1^2)\).

(b) Minimize \(\tfrac12(u_0^2 + u_1^2)\) subject to \(u_0 + u_1 = -1\): \(u_0^\star = u_1^\star = -\tfrac12\), cost \(\tfrac14\).

(c) \(f_0 = -\tfrac32\), \(f_1 = -\tfrac12\). From Q16(b): \(x_h(\tau) = 1 - \tfrac32(\tau - \tau^2/2) - \tfrac14\tau^2 = 1 - \tfrac32\tau + \tfrac12\tau^2\), and \(x_h(1) = 0\).

(d) \(x_h' = -\tfrac32 + \tau\), \(u_h = -\tfrac12\), so \(r(\tau) = -\tfrac32 + \tau + \left(1 - \tfrac32\tau + \tfrac12\tau^2\right) + \tfrac12 = \tfrac12\tau(\tau - 1)\). Zero at both collocation points, \(|r| = \tfrac18\) at the midpoint. The solver did its job: the collocation conditions hold exactly. But one interval with a linear control cannot represent the true optimum, whose control is smooth. That error is controlled by the mesh and the degree, never by the solver tolerance. The crane demo checked this by re-integrating the optimized control with an accurate integrator.

The general collocation condition for interior stage \(i\) of interval \(k\) reads \[ x_{k,i} - x_k - h_k \sum_j A_{ij}\, f_{k,j} = 0, \qquad f_{k,j} = f(x_{k,j}, u_{k,j}). \] Which statement is correct?

  1. a\(A_{ij} = \int_0^{\tau_i} \ell_j\): the sum integrates the interpolated slope from the start of the interval to stage \(i\) (FTC); with \(b_j = \int_0^1 \ell_j\) instead, the same line evaluated at the end gives the continuity condition for \(x_{k+1}\)
  2. b\(A_{ij} = \ell_j'(\tau_i)\), the differentiation matrix
  3. cThe integral runs from the previous stage \(\tau_{i-1}\) to \(\tau_i\)
  4. dOnly stages \(j < i\) appear in the sum

"The important point is really this equation: these are the equality constraints of the program you will be implementing." Every integral starts at the beginning of the interval, and the sum runs over all slope nodes, including those after \(i\); an entry like \(A_{23} = -1/24\) in Hermite–Simpson is a signed area, not a mistake. \(A\) and \(b\) depend only on the chosen nodes and are precomputed once. Q20core2 min

The original problem is \(\min\; c_T(x(t_f)) + \int_{t_0}^{t_f} c(x,u)\,dt\) subject to \(\dot x = f(x,u)\). To transcribe the integral cost consistently, we augment the state. Which is right?

  1. aAdd \(z\) with \(\dot z = c(x,u)\) and \(z(t_0) = 0\); the objective becomes \(c_T(x_N) + z_N\), and \(z\) is collocated with the same scheme as \(x\), so trapezoidal collocation yields the trapezoidal rule for the cost and Euler yields the rectangle rule
  2. bAdd \(z\) with \(z(t_0) = c(x_0,u_0)\), the first immediate cost
  3. cKeep the integral and always discretize it with Simpson's rule, whatever the collocation scheme
  4. d\(z\) is not a decision variable; it is computed after the solve

The augmented dynamics are \(\tilde f = (f, c)\) on \(\tilde x = (x, z)\); \(z\) starts at zero because it accumulates, and \(z(t_f) = \int c\). In discrete time it is the running sum. Because \(z\) obeys the same collocation conditions as \(x\), the quadrature is prescribed by the scheme ("you don't want to choose an arbitrary quadrature method"). This turns a Lagrange or Bolza problem into a Mayer problem with only a terminal cost.

Q212 min

CasADi and similar tools write collocation in the differentiation form: interpolate the state on each interval and impose \(\sum_r D_{ir}\,\hat x_{k,r} = h_k\, f(\cdot)\) at the collocation points. How does it relate to the integration form from Q18?

  1. aIntegration form interpolates the slopes and integrates them (FTC); differentiation form interpolates the state and differentiates it at the collocation points. With the same nodes and degrees they describe the same set of feasible trajectories
  2. bThe differentiation form requires automatic differentiation of \(f\)
  3. cThe two forms have different optimal solutions
  4. dThe differentiation form has no continuity constraint between intervals

Both are "the slope of the polynomial equals what \(f\) dictates at the collocation points"; one builds the slope match in and constrains the state values, the other builds the state interpolant in and constrains its slopes. \(D\) is the precomputed differentiation matrix, nothing is autodiffed. Continuity comes from a shared endpoint value in both forms. Off the solution the residuals and their conditioning differ, so solvers may behave differently, but the feasible set is the same.

Rule of thumb from class: the control polynomial has one degree less than the state polynomial. Which pairing follows it, and what is actually applied to the system after the solve?

  1. aEuler with a zero-order hold, trapezoidal with a linear control, Hermite–Simpson with a quadratic control; the system receives the control polynomial induced by the optimal nodal values, not the bare nodal values
  2. bEuler with a linear control, trapezoidal with a quadratic control; the system receives the nodal values at the mesh times
  3. cThe control degree must equal the state degree so that the collocation condition is square
  4. dThe control is always piecewise constant whatever the scheme

Integration raises the degree by one, so a state of degree \(d\) goes with a slope, hence a control, of degree \(d - 1\): Euler 1/0, trapezoidal 2/1, Hermite–Simpson 3/2. Q25core3 min

MPPI, one control, nominal plan \(u = 0\). Three perturbations \(\epsilon = (-1, 0, 1)\) with corrected costs \(\tilde S = (0, \log 2, \log 2)\) and temperature \(\lambda = 1\). The updated control \(u^+ = u + \sum_i w_i \epsilon_i\) is

  1. a\(-\tfrac14\)
  2. b\(0\)
  3. c\(-1\)
  4. d\(+\tfrac14\)

Weights \(\propto e^{-\tilde S_i/\lambda} = (1, \tfrac12, \tfrac12)\), normalized to \((\tfrac12, \tfrac14, \tfrac14)\), so \(u^+ = -\tfrac12 + 0 + \tfrac14 = -\tfrac14\). The ratio of two weights is \(e^{-(\tilde S_i - \tilde S_j)/\lambda}\): \(\lambda\) amplifies or shrinks differences between candidates. As \(\lambda \to 0\) the weights collapse onto the best sample (\(u^+ \to -1\), a soft argmax becoming an argmax); as \(\lambda \to \infty\) they flatten to \(\tfrac13\) each and \(u^+ \to 0\). Subtracting the minimum cost \(\rho\) from every \(\tilde S_i\) changes nothing: it is a numerical trick for the exponentials.

Q263 min

The exponential weighting solves \(\min_Q\; \mathbb E_Q[S] + \lambda\, D_{\mathrm{KL}}(Q \,\|\, P_0)\), whose solution is \(P^\star \propto P_0\, e^{-S/\lambda}\), and the update sets \(u_k^+ = \mathbb E_{P^\star}[v_k]\). When the samples are drawn around the current plan \(\mathbf U \ne 0\) rather than from \(P_0\), the costs are corrected to \(\tilde S_i = S_i + \lambda\sum_k u_k^\top\Sigma^{-1}\epsilon^{(i)}_k\). Why?

  1. aThe expectation is under \(P^\star\), built on \(P_0\), but the samples come from \(Q_{\mathbf U}\): a change of measure (importance sampling) multiplies each sample by \(p_0/q_{\mathbf U}\), and the log of that ratio is this term, up to a constant that cancels in the normalization
  2. bIt adds the control-effort penalty \(\tfrac12 \mathbf u^\top\Sigma^{-1}\mathbf u\) to the cost
  3. cIt is the numerical-stability shift \(\rho\)
  4. dIt makes the weights sum to one

Multiply and divide by \(q\): \(\mathbb E_p[g] = \mathbb E_q[g\, p/q]\), an unbiased change of measure whose variance can blow up when \(q\) is small where \(p\) is not. For two Gaussians with the same \(\Sigma\), \(\log\frac{p_0(\mathbf V)}{q_{\mathbf U}(\mathbf V)} = -\sum_k \left[\mathbf u_k^\top\Sigma^{-1}\boldsymbol\epsilon_k + \tfrac12 \mathbf u_k^\top\Sigma^{-1}\mathbf u_k\right]\); the second term is the same for all samples and drops out of the self-normalized estimator. Control effort enters the objective through the KL term (with \(\Sigma = I\) it is \(\sum \|\mathbf u_k\|^2\)), not through \(S\), which is why \(S\) contains state costs only. Omitting the correction converges to the wrong mean no matter how many samples you draw.

Rehearses: importance sampling as the change of measure behind the corrected costs.

Q27core2 min

Is MPPI a simultaneous or a sequential method, and what follows?

  1. aSequential: every candidate is a rollout from the current state, there are no state decision variables, so there is no built-in way to impose hard state constraints; the result is an open-loop plan until it is replanned inside a receding-horizon loop
  2. bSimultaneous: the sampled trajectories play the role of state variables
  3. cClosed-loop by construction, because sampling many futures amounts to feedback
  4. dSequential, and it requires the gradient of \(f\) for each rollout

MPPI begins with the single-shooting rollout and changes how candidate inputs are combined: a softmax-weighted average instead of a gradient step. No derivatives of \(f\) or of the cost are needed, and the rollouts run in parallel on a GPU. "Resist the temptation to view everything as finding a policy. We're finding plans here." Feedback only appears when the loop replans from the newly observed state and applies the first control. Constraints are handled by barriers, penalties, or by filtering candidates, since an average of feasible plans can be infeasible.

In the finite-horizon problem solved at each MPC step, a terminal cost \(V_f(\mathbf x_N)\) and a terminal set \(\mathbf x_N \in \mathcal X_f\) are added. What are they for?

  1. a\(V_f\) stands in for the cost-to-go beyond the horizon (the value function from \(\mathbf x_N\)), and \(\mathcal X_f\) is a region from which a known safe, stabilizing controller can take over; without them a short horizon ignores consequences past step \(N\)
  2. b\(V_f\) is the immediate cost at step \(N\) and \(\mathcal X_f\) is the set of reachable states
  3. cThey are needed only when the task has a fixed end time
  4. dThey replace the need to replan

The true objective runs to the end of the task or to infinity; the horizon truncates it, and \(V_f\) approximates the tail \(\sum_{k \ge N} c\). That is the same object as the value function in dynamic programming, and one can learn it. For a task with a fixed end time, the horizon shrinks as the end approaches and the true terminal cost takes over, so the controller does not optimize past completion.
