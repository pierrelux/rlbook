A. Discounting and policy evaluation random horizon, Neumann series, cost

Q1core1 min

A discounted problem with factor \(\gamma\) is the same as a finite-horizon problem whose horizon \(N\) is random, with \(P(N = n) = (1-\gamma)\gamma^{n-1}\). With \(\gamma = 0.9\), what is the expected horizon \(\mathbb E[N]\)?

  1. a0.9 steps
  2. b9 steps
  3. c10 steps
  4. dInfinite, since the problem is infinite-horizon

For a geometric horizon starting at \(n = 1\), \(\mathbb E[N] = 1/(1-\gamma) = 10\). With \(\gamma = 0.99\) it becomes 100. A small change in \(\gamma\) is a large change in how far ahead the agent effectively looks, which is why \(\gamma\) is as much a modelling choice as a knob.

Rehearses: reading \(\gamma\) as an effective horizon.

Q2core3 min, on paper

Policy evaluation solves \((I - \gamma P_\pi)\,v = r_\pi\), where \(P_\pi\) is a stochastic matrix: each row sums to 1.

  1. Explain why \(I - \gamma P_\pi\) is invertible when \(0 \le \gamma < 1\).
  2. What goes wrong at \(\gamma = 1\)? Hint: what is \(P_\pi \mathbf 1\), where \(\mathbf 1\) is the vector of all ones?

(a) For a stochastic matrix, \(\|P_\pi\|_\infty = \max_s \sum_j P_\pi(s, j) = 1\), so \(\|\gamma P_\pi\|_\infty = \gamma\). The spectral radius is bounded by any induced norm, so \(\rho(\gamma P_\pi) \le \gamma < 1\). Then the Neumann series \(\sum_{t \ge 0} (\gamma P_\pi)^t\) converges and equals \((I - \gamma P_\pi)^{-1}\).

(b) Rows summing to 1 means \(P_\pi \mathbf 1 = \mathbf 1\): 1 is an eigenvalue of \(P_\pi\). At \(\gamma = 1\), \((I - P_\pi)\mathbf 1 = 0\), so the matrix is singular. Values are also only defined up to an added constant, which is one reason the average-reward criterion needs its own treatment.

Rehearses: the stochastic-matrix and \(\gamma < 1\) argument behind the Neumann series.

Q3core3 min

You have \(n = 10{,}000\) states and \(\gamma = 0.9\). Option A: call np.linalg.solve once, roughly \(n^3\) operations. Option B: iterate \(v \leftarrow r_\pi + \gamma P_\pi v\), roughly \(n^2\) operations per step, until the error has shrunk by a factor \(10^{-6}\). Which is closer to the truth?

  1. aB needs about 10 iterations and is about 10,000 times cheaper
  2. bB needs about 130 iterations and is about 100 times cheaper
  3. cB needs about \(10^6\) iterations, so A is cheaper
  4. dB never reaches that accuracy without a matrix inverse

Each step contracts the error by \(\gamma\) in the \(L_\infty\) norm, so we need \(0.9^k \approx 10^{-6}\), that is \(k \approx 6 / \log_{10}(1/0.9) \approx 131\). B costs about \(131 \times 10^8 \approx 1.3 \times 10^{10}\) operations against \(10^{12}\) for A. Each step is just a matrix-vector product and a vector addition. The trade depends on \(\gamma\): with \(\gamma = 0.999\) it takes about 14,000 iterations and the direct solve wins again.

Rehearses: the cost of direct versus iterative policy evaluation.

B. Contractions and optimality norms, greedy policies, Q functions

Q4core1 min

True or false: "\(L_\pi v = r_\pi + \gamma P_\pi v\) is a \(\gamma\)-contraction in the \(L_\infty\) norm, so it is also a \(\gamma\)-contraction in any other norm, for example a weighted \(L_2\) norm."

  1. aTrue: on a finite-dimensional space all norms are equivalent
  2. bFalse: contraction results depend on the norm, and \(L_\pi\) need not contract in a weighted \(L_2\) norm
  3. cTrue, but only when \(P_\pi\) is symmetric
  4. dFalse: \(L_\pi\) is not a contraction in any norm because it is affine

Norm equivalence only gives \(\|x\|_a \le c\,\|x\|_b\) with some constant \(c\), which can destroy a modulus \(\gamma < 1\). "Whenever you see a theorem, don't fall into the temptation of generalizing it to any other norm." This norm dependence is one of the technical roots of the deadly triad, which we will meet once we add function approximation. Being affine is no obstacle: the constant \(r_\pi\) cancels in \(L_\pi u - L_\pi v = \gamma P_\pi (u - v)\).

Rehearses: stating which norm a contraction holds in.

Q5core2 min

To act greedily from \(v^\star\) you compute \(\pi(s) \in \arg\max_a \big\{ r(s,a) + \gamma \sum_j p(j \mid s, a)\, v^\star(j) \big\}\). From \(q^\star\) you compute \(\pi(s) \in \arg\max_a q^\star(s, a)\). Why does model-free RL prefer the second form?

  1. aBecause \(q^\star\) gives a better policy than \(v^\star\)
  2. bBecause the greedy policy from \(q^\star\) is stochastic, which gives exploration
  3. cBecause the first form needs \(r\) and \(p\), which a model-free agent never gets; the second only queries \(q^\star\) over actions
  4. dBecause \(q^\star\) is cheaper to store than \(v^\star\)

Both give the same optimal policies, since \(v^\star(s) = \max_a q^\star(s, a)\). The difference is what you need to act. In model-free RL we observe states and sampled rewards but are never handed \(P\) or \(r\); \(q\) has already folded the expectation over next states in, so a black box such as a network can be queried over the action axis. It is also larger, \(|S| \times |A|\) entries instead of \(|S|\). When the transition model is tractable, as in many OR problems, work with \(v\) and compute exactly.

Rehearses: what each value function needs in order to act.
