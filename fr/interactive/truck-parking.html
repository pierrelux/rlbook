Each optimizer checkpoint is a complete 40-second plan for the tractor's speed and steering. Advancing simulation time follows that fixed plan; it does not replan. Checkpoints are not consecutive iterations: early iterations are all kept, later ones are geometrically spaced, and the cost curve uses every iteration.
