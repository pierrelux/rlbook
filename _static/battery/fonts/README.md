These font files are vendored so the generated battery SVG and PDF use the
book's typography without a network request.

- `IBMPlexSans-Regular.ttf`, `IBMPlexSans-SemiBold.ttf`, and
  `IBMPlexMono-Regular.ttf` come from the official
  [IBM Plex repository](https://github.com/IBM/plex) and are covered by
  `IBM-Plex-LICENSE.txt`.
- `Newsreader.ttf` comes from the
  [Google Fonts Newsreader family](https://github.com/google/fonts/tree/main/ofl/newsreader)
  and is covered by `Newsreader-OFL.txt`.
